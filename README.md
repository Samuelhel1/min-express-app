# Min Express-app

Ett litet Node.js-projekt med Express och EJS. Projektet visar hur man delar upp kod i flera filer och kopplar ihop dem med JavaScript-moduler (`import` och `export`).

## Starta projektet

1. Installera paketen:
```
   npm install
```
2. Starta servern:
```
   npm start
```
3. Öppna http://localhost:3000 i webbläsaren.

## Mappar

- `routes/` – sidornas adresser (index, about, notFound)
- `views/` – EJS-mallar med HTML
- `public/` – filer som webbläsaren hämtar direkt (main.js)
